Hunting-Queries-Detection-Rules

This repository is designed to share KQL (Kusto Query Language) queries that are easy to understand and freely available for anyone to use. The goal is to enhance detection capabilities by leveraging logs from Microsoft security products. While not all suspicious activity triggers alerts by default, many such behaviors can be identified through log analysis.

The repository includes a variety of resources such as detection rules, hunting queries, and visualizations to support threat detection and investigation.
